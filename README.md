# CNAI(Computer Not AI)
> **"You can't become an engineer by using ready-made code. A true engineer is one who writes their own code. - by Computer-Eymen"**

CNAI (Computer Not AI) aims to revive the discipline of programmers, which has weakened with the growth of artificial intelligence and the development of code.

This project aims to develop software by understanding the logic, algorithms, and fundamental computer science, without relying on ready-made code generators.

I'm doing this as a hobby; it won't be a huge project like GNU or Linux.

Please add your Github account name and address to the DEVELOPERS.md file.

---

## Our Goal

* **Preserving the Fundamentals:** To truly learn and teach how code works.
* **Educational Focus:** To provide clear and understandable examples that reinforce programming logic.
* **Practical Tools:** To develop useful applications, entirely written by humans, that can be used in daily life and on systems.

---

## Project Structure

The main sections of the project will be:

- `tutorials/`: Basic algorithms and training content.
- `tools/`: Practical system tools developed for daily use.
- `docs/`: Guides on computer science and programming philosophy.

---

## How Can You Contribute?

This project is open to community contributions! If you value the craft of coding and basic computer science:

1. Fork the repository.
2. Add a new feature or training content (**provided it is written without using AI tools**).
3. Commit your changes and create a `Pull Request`.
