# Calculator

This calculator is our first project. Yes, there are many calculators on the market, but the purpose of this repository is to prove what humanity is capable of, so I wanted to include this one. This 

calculator consists of 6 operations: addition, subtraction, multiplication, division, remainder, exponent, square root, and arithmetic mean. This program is written in C and will grow further, but 

for testing purposes, we will upload it to my separate repository, Calculator-versions, not this one. We will test it there and then upload it to this main project.

To run:

For Linux:

Step 1: First, download the main.c file I provided in the releases section.

Step 2: Then, go to the address where the file was downloaded (usually in the downloads directory) and type **cd ~/Downloads** in the terminal.

Step 3: Then type the following command in the terminal: **gcc main.c -o main -lm && ./main** and press Enter. The application will then run.

For Windows:

Step 1: First, download the main.c file provided in the releases section.

Step 2: Then, go to the location where the file was downloaded (usually in the downloads directory) and type **cd ~/Downloads** in the terminal.

Step 3: Then, type the following command in the terminal: **gcc main.c -o main.exe -lm**.

Step 4: Go to the same directory and double-click the .exe file to open it. The application will then run.
